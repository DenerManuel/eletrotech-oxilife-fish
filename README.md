# 🚀 Eletrotech & Oxilife Fish - Site Dinâmico

> Projeto Integrador desenvolvido pelos alunos do 2º Período de Análise e Desenvolvimento de Sistemas (Grupo 3).

## 📌 Sobre o Projeto
Plataforma web institucional e catálogo dinâmico com arquitetura Mobile First desenvolvido para a empresa **Eletrotech** (Marechal Cândido Rondon/PR), com foco no produto estrela **Oxilife Fish** (sonda inteligente para monitoramento de oxigênio na piscicultura).

## 👥 Equipe de Desenvolvimento (Grupo 3)
- **Líder de Projeto:** Dev Geral & Arquitetura da Aplicação
- **Rodrigo:** Vice-Líder / Estratégia, Brainstorming e Decisões
- **Augusto:** UI/UX Design, Prototipação e Estilização CSS
- **Eduardo:** Documentação Técnica e Acadêmica
- **Maicon:** Suporte Operacional, Mídias, Testes e Trello

## 📂 Estrutura de Pastas do Projeto
- `/assets` -> Imagens, logos e mídias da sonda Oxilife Fish
- `/css` -> Arquivos de estilização e responsividade
- `/js` -> Lógicas de interatividade e gerenciamento do catálogo
- `/docs` -> Documentação acadêmica (Requisitos, UML, Relatórios)

## 🛠️ Tecnologias Utilizadas
- HTML5 (Estrutura)
- CSS3 (Estilização Responsiva)
- JavaScript ES6+ (Dinamismo e Validações)
